# Student Management System

A menu-driven Student Management System built using Python and PostgreSQL.

## Features
- Add student data
- Update student records
- View all students
- Search student by roll number
- Delete student data

## Technologies Used
- Python
- PostgreSQL
- psycopg2

## Concepts Practiced
- CRUD Operations
- SQL Queries
- Database Connectivity
- Python Functions
- Exception Handling

## How to Run

1. Install PostgreSQL
2. Install psycopg2
